DistributedDownstreamUserTokenStore

Default distributed cache-backed authenticated session token store that encrypts a versioned session aggregate with ASP.NET Core Data Protection. This implementation is suitable for single-instance deployments unless the host replaces it with a store that provides cross-node atomic compare-and-swap guarantees.
